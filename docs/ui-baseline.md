# 台账管理 Web 交互基线（草案）

## 1. 页面结构

侧边栏分为：工作台、业务台账、网络设备、审核中心、缺项工作台、导入导出、回访与通话、系统管理。首页显示待审核、缺项数量、到期业务、当前拨号状态和最近异常。

## 2. 台账列表

- 顶部搜索支持业务号码和客户名称模糊查询。
- 筛选支持县分、网格、服务状态、业务类型、维护责任人、缺项和变更状态。
- 表格默认固定业务号码、客户名称、县分、网格；业务字段与设备字段用分组列切换，不默认挤出 23 列。
- 服务端分页、列显示选择、排序和可保存筛选视图。
- 手机号按权限显示完整值，否则只显示首尾部分。

## 3. 详情与编辑

点击行打开右侧详情抽屉，分为业务信息、设备关联、联系人、审核历史、通话记录五个页签。业务和网络维护人员只能编辑自己有权限的分组。

编辑状态显示必填提示、格式错误、字典选择和缺项提醒；保存为草稿后再提交审核。提交前显示字段级变更摘要，避免用户不知道将提交什么。

设备使用可增删的关联子表，不要求用户在一行中塞入多台设备。作废操作显示关联业务、计划和通话影响，并要求确认理由。

## 4. 审核中心

审核中心按待审核、已退回、已驳回、已应用筛选，显示提交人、域、范围、批次、等待时间和缺项数量。审核详情采用“当前正式值 / 提交值”并排对比，支持逐字段接受或退回，退回必须填写原因。

低风险、同类型、同批次的变更可批量审核；含唯一键冲突、作废、联系人电话或大量缺项的批次必须逐条处理。

## 5. 导入、缺项与导出

导入向导依次完成文件上传、表头映射、类型校验、重复检查、缺项检查、差异预览和提交审核。原始行与错误信息保留在暂存区，不能直接覆盖正式表。

缺项工作台按字段和责任人聚合，可直接进入详情补齐并提交变更。导出使用当前用户的数据范围和脱敏规则，并记录导出条件与批次。

## 6. 回访入口

业务或设备详情页提供“立即拨打一次”；计划页提供定时规则和到期规则。三者都进入统一任务队列，拨号前显示目标联系人、号码、话术版本和预计执行时间。通话页突出未接通及有效时长不足 10 秒的记录，并保留串口事件时间线。

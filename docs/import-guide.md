# 台账导入说明

## 表头识别

导入读取工作簿的活动工作表：第 2 行是表头，第 3 行开始是数据。系统按标准中文字段
名识别表头，忽略空白和全角/半角差异；字段名后的括号说明不参与匹配。例如
`设备编码（资产及非资产）` 会识别为 `设备编码`。每个标准字段必须恰好匹配一个来源列，
缺列或同名候选列会阻止导入，避免静默错列。

业务字段为 `号码` 至 `客户经理联系电话`；网络字段从 `网络维护责任人`、
`网络维护责任人联系电话` 开始，连同 `设备属性` 至 `设备未回收原因` 一起进入 network
审批域。`业务记录ID`、`业务版本`、`设备记录ID`、`设备版本` 是导出回传时
使用的系统校验字段，导入暂存更正时保持只读。

## 暂存更正

导入报告不重复显示列映射。操作人员在暂存行明细中点击“更正”，按业务或设备域选择
字段并保存；保存后整批重新校验，原始上传值和人工更正值都会保留。县分、网格、服务
状态、业务类型、设备属性、设备类型、回收状态和网络维护联系人等字段支持输入时自动补全，也
允许直接输入自定义值；最终是否可进入正式台账仍由服务层校验和审核链路决定。
